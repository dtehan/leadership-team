# Profiles

Folder names are stable profile identifiers. The initial skeleton includes
`leader` = CEO, `cfo`, `cto` and `coo`; add managers, DBAs or other professionals
using the same dossier structure. Each person folder has an `index.md` with
`person:`, `title:` and optional `areas:` front-matter.

Profiles are reusable across named teams. A team's definition chooses its leader,
participants and voting assignments; none are implied by a person's profile type.
`moonshot` and `contrarian` are optional synthetic facilitation perspectives, not
people or automatic team members.
